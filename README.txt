SPPU SE Computer Engineering - DSL Assignments 1-10

Requires Python 3. No additional packages are needed.
Open a terminal in this folder and run, for example:
python 01_library.py
On Windows, you can also use: py 01_library.py

Each numbered file is independent. Enter numbers when prompted for numeric input.
For lists, enter values separated by spaces. Choose 0 to exit menu programs.

01 Library: separate member borrow totals and book borrow totals; average,
   zero-borrow members, highest/lowest books including ties, mode of book
   borrow counts including ties, and operation complexity.
02 Searching: linear search and binary search after sorting customer IDs.
   Indices start at 0. Binary search reports an index in the sorted list.
03 Salaries: selection sort, bubble sort, and up to five highest salaries.
04 Editor: replace the complete document, undo, redo, and display.
   A new change clears the redo history.
05 Events: add, process oldest, display, cancel by unique event ID.
06 Students: singly linked list; add, delete, update, search, sort, display.
   Roll numbers are unique. Sort by roll or marks in either direction.
07 Chaining: ten buckets, integer keys and text values; insert/update,
   search, delete, display. Hash function: key % 10.
08 Linear probing: ten slots; insert, search, delete, display.
   Deleted markers preserve collision searches; duplicate keys are rejected.
09 Graph: undirected user-entered routes; BFS uses an adjacency list and
   DFS uses an adjacency matrix. Traversals cover the start's component.
10 BST: integer keys; insert, delete, search, ascending and tree display.
   Duplicate keys are ignored. Tree display is sideways.

These are small in-memory practice programs. Records reset when closed.
The ten Python programs contain no comments or docstrings.
See TEST_RESULTS.txt for the verification performed.
